# Conflicts and gaps

Every disagreement found between the three handoffs, the code and the spec, as of the snapshot in
`SYSTEM_STATE.md` (17 October 2026, 16:29 to 16:37). The code wins; each row says which document is wrong.

Kinds: **Doc** (a document is wrong), **Code** (code or config to change), **Env** (the installed
environment), **Owner** (only the owner can decide; see `OWNER_DECISIONS.md`).
Severity: **High** (can show a wrong result, lose data or mislead a decision), **Medium**
(misleads a reader or blocks a plan item), **Low** (cosmetic or tidy-up).
