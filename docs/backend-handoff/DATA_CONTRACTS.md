# Data contracts

Everything is files under the project folder. Paths come from `config.py`. All writes go
through `storage.py`: a uniquely named temporary file in the same folder is flushed to disk,
then `os.replace`d over the target, so a reader sees the old file or the new one, never part
of one. Every read-modify-write holds that file's lock (see Lock files below). Reads take no lock.

## `data/samples.csv`
One row per training sample. Written by `data_collector.DatasetStore` (Data collector page and
`import_videos.py`). Saving a recording rewrites the whole file with the new rows at the end,
under the lock, so a failed save leaves the previous file intact. `DatasetStore.fingerprint()`
is the SHA-256 of the file's bytes.

| Column | Type | Meaning |
|---|---|---|
| `session_id` | string, 12 chars | One recording. Training holds out whole sessions. Random for webcam recordings; the first 12 hex characters of the file's SHA-256 for imported videos |
| `label` | string | Gesture id, lowercase slug (`first_meme`, `none`) |
| `person` | string | Who recorded it, may be empty |
| `timestamp` | ISO local time | When the sample was taken, for example `2026-10-13T09:55:01` |
| `f000` ... `f125` | float | The feature vector, written with `%.6g` |

Feature layout (`hands` mode): `f000-f062` right hand (21 landmarks x 3), `f063-f125` left hand,
mirrored. A missing hand is all zeros. In `hands+pose` mode `f126-f224` hold 33 pose landmarks x 3.

Text columns are read back exactly as written (pandas' `keep_default_na=False`): a gesture named
`null` or `nan`, or a person named `NA`, stays that text, and an empty cell is empty text.

Current contents (17 October 2026): 380 rows, 16 recordings, 5 labels.
Only landmark numbers are stored. No images or video, ever.

## `data/dataset_meta.json`
```json
{ "feature_mode": "hands", "feature_length": 126 }
```
Written (atomically) with the first sample. `DatasetStore` refuses to load or append if it does
not match `config.FEATURE_MODE`.

## `models/gesture_model.joblib`, `models/label_mapping.json`, `models/training_report.json`
Written together by `train_model.save_artifacts`: all three go to temporary files first, then
are renamed, the report last. Never write one without the others; `Predictor.load`
cross-checks them, including the model file's SHA-256 against `artifacts.model_sha256`.

`label_mapping.json`: class index (string) to gesture id.
```json
{ "0": "first_meme", "1": "meme_3", "2": "meme_4", "3": "none", "4": "second_meme" }
```

`training_report.json` top-level keys: `trained_at`, `sklearn_version`, `feature_mode`,
`feature_length`, `model_name`, `labels`, `dataset` (incl. `fingerprint`, the SHA-256 of
`samples.csv` as trained on), `evaluation` (incl. `per_recording`), `cost` (l2 options,
history and `augmentation`: copies_per_sample, rotation_deg, noise, seed; `steps` counts every
step tried, `history` numbers only the steps kept, so after a momentum restart its last step is
below `steps`, see the ML `ARCHITECTURE.md`), `train_accuracy`, `test` (accuracy, cost, macro_f1, per-class metrics, confusion
matrix, cutoff table), `warnings` (gesture ids; the UI shows names), `artifacts`
(`model_sha256`). Reports written before 17 October have no `fingerprint`, `artifacts` or
`cost.augmentation`; all three are optional when reading. Staleness then falls back to the
row count, and the report text says no augmentation was used.

The joblib file is a pickled `gd_model.GradientDescentClassifier`. Pickles run code when loaded:
only load model files this project wrote.

## `models/mediapipe/*.task`
Google's MediaPipe models, downloaded by `download_models.py`. Not generated by the project.

## `assets/memes/memes.json`
Gesture id to meme record. Written by `dataset_manager.MemeLibrary`.

```json
{
  "first_meme": {
    "gesture_name": "First meme",
    "meme_title": "",
    "image_path": "assets/memes/first_meme.jpeg",
    "ball_knowledge_level": "",
    "description": ""
  }
}
```

- `image_path` is relative to the project root and must be inside `assets/memes/`. Uploaded
  images are copied there as `<gesture id>.<ext>`.
- Allowed image types: `.jpg .jpeg .png .webp .gif`, at most 10 MB (`MEME_MAX_UPLOAD_MB`,
  must equal `server.maxUploadSize` in `.streamlit/config.toml`; a test checks this). The file is
  also checked by its content: it must be a JPEG, PNG, WebP or GIF image whatever its name
  (`dataset_manager.BROWSER_IMAGE_FORMATS`), so a TIFF renamed `.png` is refused.
- Replacing an image writes the new file, then `memes.json`, and only then deletes the old image.
  If `memes.json` cannot be written, the previous image and record are put back. Removing a
  meme (`dataset_manager.py <gesture> --remove`) also saves `memes.json` before deleting the image.
- Text limits: name 60, title 80, rating 40, description 400 characters.
- `none` has no record and never shows a meme.
- Titles, ratings and descriptions belong to the owner. Leave them empty unless they set them.

## In-memory only (never written to disk)
- Recent detections (`predictor.DetectionLog`): last 10 per browser session. The privacy page
  promises this. Changing it needs a privacy page update and the owner's agreement.
- Camera frames: processed and discarded.

## Lock files
Hidden, empty files beside what they protect, created on first use. The operating system
releases a lock when the process holding it exits, so a crash never leaves one stuck, and
deleting them while nothing is running is harmless.

| Lock file | Held while |
|---|---|
| `data/.samples.csv.lock` | saving a recording, undoing one, deleting a gesture's samples (waits up to 10 s) |
| `assets/memes/.memes.json.lock` | saving or removing a meme (waits up to 10 s) |
| `models/.gesture_model.joblib.lock` | a whole training run (does not wait: a second run fails at once) |

## Environment variables
| Variable | Default | Effect |
|---|---|---|
| `BALLKNOWLEDGE_DATA_DIR` | `data/` | Where `samples.csv` and `dataset_meta.json` live |
| `BALLKNOWLEDGE_MODEL_DIR` | `models/` | Where the trained model, labels and report are read and written |

`assets/memes/` and `models/mediapipe/` have no override.
